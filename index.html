地震3Dモニターについて

見えているもの

  • 地面の下に浮かぶ光の点が震源です。小さな点（過去の震源）の色は深さ、大きな点（最近の地震）の色は最大震度、大きさはマグニチュードを表します。
  • 日本列島の下へ斜めに沈んでいく震源の帯は、太平洋プレートやフィリピン海プレートが沈み込んでいる形そのものです（和達－ベニオフ帯）。「南から」「東から」の視点で横から見るとよくわかります。
  • 赤い線は海溝・トラフ（プレート境界）です。深さと地形の起伏は見やすさのため強調しています（初期値：深さ×2、起伏×10）。

操作

  • ドラッグで回転、右ドラッグ（2本指）で移動、ホイール（ピンチ）でズーム。
  • 地震の点や一覧をクリックすると、震源へ移動して揺れの広がり（P波・S波）と各地の震度を再生します。
  • 下のタイムラインで表示期間を切り替え、▶で地震活動を早送り再生できます。バーをドラッグすると好きな時点を表示できます。
  • 右下の「地球」（G）、または大きくズームアウトすると地球儀になり、世界の地震とプレート境界を表示します。地球儀で日本に近づくと、元の詳しい表示に戻ります。
  • 左の一覧の「過去の大地震」タブから、東日本大震災や能登半島地震などを選ぶと、本震の前後の地震を早送りで再生します。本震の時刻で一時停止して、揺れの広がりも見せます。
  • 右下の「断面」を押して地図上の2点をクリックすると、その線に沿って地下を切った断面を表示します。断面の近く（初期値は±50km）の震源だけが残り、画面下に距離と深さの断面図が出ます。「断面の例」から東北や伊豆・小笠原などを選ぶこともできます。
  • 右上の共有ボタンで、いま見ている表示（選んだ地震・断面・過去の大地震・地球儀・視点）をリンクにしてコピーできます。そのリンクを開くと同じ表示から始まります。
  • キーボード：Space 再生／停止、1〜4 視点、S 断面、G 地球儀、R 視点リセット、Esc 閉じる

データ

  • 地震情報・震度観測点：気象庁（防災情報JSON）
  • リアルタイム受信・緊急地震速報：P2P地震情報 WebSocket API
  • 過去の震源：USGS Earthquake Catalog
  • 地形・海底地形：Mapzen Terrain Tiles（AWS Open Data。SRTM、GMTED2010、ETOPO1 ほか）
  • 県境：dataofjapan/land（出典：地球地図日本）
  • 世界のプレート境界（地球儀）：Peter Bird (2003) PB2002（Hugo Ahlenius / Nordpil による変換、ODC-By 1.0）
  • 描画：three.js

ご注意

このツールは防災の参考情報です。緊急地震速報の表示は遅れたり届かなかったりすることがあります。揺れの到達秒数は単純な速度（P波 毎秒7km・S波 毎秒4km）による目安です。身を守る行動は、気象庁や自治体の発表・テレビ・ラジオ・スマートフォンの緊急速報に従ってください。
